Desktop:
Start communications server on startup



Webapp:
Authentication required

user visits webapp:
    GET /programs
    Display list of programs to turn on/off

user turns on an application:
    POST /programs/{id}/start

user turns of an application:
    POST /programs/{id}/stop

REST API:
    PUT /programs:
        Update disk db with desktop programs

    GET /programs:
        return desktop programs from disk db
    

    POST /programs/{id}/start:
        while true:
            request to API web server to start the application
            if response:
                return status_code.ok
            else :
                send magic packet
                wait x seconds

    POST /programs/{id}/stop:
        while true:
            request to API web server to stop the application
            if response:
                return status_code.ok
