Desktop:
Start API web server on startup



Webapp:
Authentication required

user visits webapp:
    Finds desktop programs from disk db (which depends on authorization)
    Display list of desktop programs to turn on/off

user turns on an application:
    while !ok_status_code:
        request to API web server to start the application
        if response:
            ok_status_code = true
            update_local_disk_db
        else :
            send magic packet
            wait x seconds

user turns of an application:
    while !ok_status_code:
        request to API web server to stop the application
        if response:
            ok_status_code = true
        else :
            ?
            
function update_local_disk_db:
    Get desktop programs from api (api response depends on authorization).
    Update disk db with desktop programs
